# Roadmap

## v0.1 - Camera and landmarks

- Open webcam
- Detect one face
- Extract facial landmarks
- Estimate basic head direction
- Print status

## v0.2 - Liveness challenge

- Look center
- Look left
- Look right
- Return liveness result

## v0.3 - Face enrollment

- Capture multiple samples
- Store local face template
- Avoid storing raw images by default

## v0.4 - Face verification

- Compare current face against enrolled template
- Return exit code 0 or 1

## v0.5 - PAM proof of concept

- Integrate with sudo only
- Keep password fallback

## v1.0 - Fedora-ready prototype

- authselect profile notes
- SELinux notes
- RPM packaging draft
