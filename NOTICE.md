# Notice

`faceauth-linux` is an independent personal software engineering and research-oriented project.

The project explores local face-based authentication for Linux systems using webcam access, facial landmarks, liveness checks and future PAM-ready verification.

This repository does not include private institutional code, proprietary datasets, confidential material or unpublished third-party assets.

## Project scope

The current scope is experimental and focused on:

- Linux camera access;
- facial landmark detection;
- basic liveness validation;
- local-first authentication workflows;
- Fedora-first development notes;
- future PAM integration research.

## Security notice

This project is not intended to replace passwords completely.

Password fallback must remain available in any authentication-related implementation.

## Third-party components

This project may use third-party open source libraries, models or tools. Any required dependency should be documented in the repository or related documentation.

Local model files, captures, biometric templates or personal test data must not be committed to the repository.
